# Dataset download instructions

Recommended starting points:
1. Historical IPL (2008–2024) project dataset: https://github.com/waquararshadkhan/ipl-analytics
2. Structured IPL 2026 datasets: https://github.com/sachin-dul/openIPL
3. 2026 ball-by-ball dataset: https://github.com/heisenricher/IPL-2026-BALL-BY-BALL-DATA-
4. Original source and formats: https://cricsheet.org/

Download the actual CSVs from the repositories/source. Place raw files in a `Raw` subfolder and cleaned, standardized files in a `Cleaned` subfolder. Check licenses and column names. The two `*_SCHEMA_TEMPLATE.csv` files in this folder contain headers only and are not populated datasets.
